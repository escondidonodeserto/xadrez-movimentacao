# Tema 4 – Movimentação de Peças de Xadrez

Este projeto implementa a lógica de movimentação das peças de xadrez em Python, conforme padrão acadêmico esperado para o Tema 4.

## Funcionalidades

- Movimentos completos de:
  - Torre
  - Bispo
  - Rainha
  - Cavalo
  - Rei
  - Peão
- Representação de tabuleiro
- Validação de posições
- Testes unitários simples
